# arXiv Digest v0.2.1

Version 0.2.1 is a technical-beta prerelease focused on a clearer and more
reliable review workflow.

## Contents

- [Highlights](#highlights)
- [Install or upgrade](#install-or-upgrade)
- [Compatibility](#compatibility)
- [Known limitations and beta feedback](#known-limitations-and-beta-feedback)

## Highlights

- Synchronization now distinguishes daily-list recovery from recent-paper
  metadata enrichment.
- Date finishing and page navigation follow chronological review flow more
  predictably.
- Review PDF actions show progress until the download actually completes.
- Paper cards and Calendar use clearer labels and accessible review-state
  styling.
- A closed dashboard now allows the loopback application to stop much sooner.
- Release artifacts are built from the tagged commit and accompanied by
  `SHA256SUMS`.

## Install or upgrade

For a fresh installation:

```bash
pipx install git+https://github.com/yuzhangmath/arxiv-digest.git@v0.2.1
arxiv-digest doctor
arxiv-digest init
```

To upgrade an existing version-0.2.0 installation, first select **Quit** and
wait for the terminal prompt. Export a current private backup if the local
state matters, then run:

```bash
pipx install --force git+https://github.com/yuzhangmath/arxiv-digest.git@v0.2.1
arxiv-digest doctor
```

## Compatibility

Version 0.2.1 retains application-data generation 2, profile schema 2, and
portable backup format 2. Upgrading from version 0.2.0 does not require a reset,
new profile, or backup import. Existing downloaded PDFs remain in their chosen
folder.

An installation from an earlier application-data generation still requires the
documented
[clean reset with recovery copy](../installation.md#clean-reset-with-recovery-copy).

## Known limitations and beta feedback

- Supported systems are macOS and Linux with Python 3.11 or newer; Windows is
  not supported.
- arXiv access is required for setup, synchronization, paper lookup, and PDF
  download. Unavailable daily lists remain visible as coverage gaps.
- The app does not run as a scheduler or login service. Keep its terminal
  process open while using the dashboard.
- Application data and portable backups are local but are not
  cryptographically encrypted by arXiv Digest. Portable backups do not include
  downloaded PDF bytes.
- Closing the browser tab is not an immediate quit operation; use **Quit** when
  possible.

For beta feedback, include the operating system, architecture, Python version,
elapsed setup time, points of confusion, and only the redacted output from
`arxiv-digest doctor`. Do not send a profile, database, backup, downloaded PDF,
or dashboard URL containing a session token.
