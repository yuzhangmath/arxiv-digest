# arXiv Digest v0.4.0

Version 0.4.0 adds native Windows support, simplifies setup and maintenance,
and improves recovery of daily lists and missing abstracts. Updates are manual.
This remains a prerelease and retains application-data generation 2.

## Native Windows support

Windows 11 or newer joins macOS and Linux as a supported native platform.
Installation uses Python 3.11 or newer and pipx; WSL is not required. The app
uses Windows data locations, file permissions and locking, the default browser,
clipboard integration, and a native PDF-folder picker. Setup can create an
optional **arXiv Digest.cmd** desktop launcher.

CI and release validation now include Windows alongside macOS and Linux, with
Python checks, Chromium and WebKit browser suites, and isolated installation
of the release wheel through pipx.

## Review and retrieval

- Recovered daily-list membership makes a date available for reading, saving,
  and finishing even when some abstracts are missing. **Retry missing abstracts**
  now works on the open date, including previously reviewed papers. Each
  recovered abstract is saved immediately, and later retries request only the
  remaining papers. Review stays usable while a retry runs.
- Settings offers retries for individual failed category/date daily lists.
  Calendar distinguishes **Retrieval failed** from empty or reviewed dates and
  shows **Some retrievals failed** when confirmed papers remain available.
- Plain HTTP 406 can trigger a paced fallback through the system `curl`
  executable for daily lists, OAI metadata pages, and abstract lookups. Daily
  lists also retain a compatibility attempt without inline abstracts. All
  responses still require normal validation; these retries cannot guarantee
  that arXiv will accept a request.
- HTTP 429 or an explicit rate-limit response pauses arXiv requests until the
  supplied retry time, or for one hour when no usable time is supplied. The
  pause survives restarts. Unattempted dates retain their prior state, and
  saved Review and Library papers remain available.
- Daily-list dates become eligible at 20:00 America/New_York, including daylight
  saving time, across retrieval, Review, Calendar, and coverage counts. Status
  and Settings consistently count a date as failed when one category failed
  and another is pending; category details retain the pending work.

## Setup and daily use

First-run setup asks for categories, coverage, a tested PDF folder, profile
confirmation, and an optional launcher. Personalization moves to Interests,
where **Refresh suggestions** builds or resumes a bounded 90-day paper sample.
Selected seed papers, terms, and authors take effect only after **Update interests**.

New PDF downloads use all authors' surnames followed by the paper title,
without an arXiv ID or version prefix. Existing filenames remain unchanged,
and new collisions receive a numbered suffix. Filename associations survive
folder changes and portable restores; missing PDF files remain marked absent.

Settings retains browser backup export and provides terminal restore
instructions. To restore, select **Quit**, wait for the app to stop, and run
`arxiv-digest import BACKUP.zip`. Import still validates the archive, asks for
a PDF destination, and creates a verified private recovery backup before
replacing existing state.

Navigation prevents late responses and scheduled refreshes from replacing the
newly opened view. PDF completion updates stay with the view that started them.

## Install or upgrade

The `v0.4.0` tag must appear on the
[releases page](https://github.com/yuzhangmath/arxiv-digest/releases) before
using these commands. Fresh installations on macOS, Windows, or Linux should
follow [Install arXiv Digest](../installation.md#install-arxiv-digest), then run
`arxiv-digest init`. Use PowerShell on Windows.

Existing generation-2 pipx installations, including 0.3.0 and 0.3.1, require
a manual upgrade. Select **Quit**, wait for the app to stop, and run these
commands one at a time from a private folder:

```bash
arxiv-digest export arxiv-digest-before-0.4.0.zip
pipx install --force git+https://github.com/yuzhangmath/arxiv-digest.git@v0.4.0
arxiv-digest doctor
arxiv-digest
```

Continue only after the export succeeds; choose a new backup filename if it
already exists. Confirm that `doctor` reports `arXiv Digest 0.4.0`, then check
your interests, Library, review progress, and PDF folder. Completed setup
should remain completed. If you use the desktop launcher, quit again and run
`arxiv-digest install-launcher` to refresh it, then verify it opens the app.

See the [complete generation-2 upgrade guide](../installation.md#upgrade-within-application-data-generation-2)
for installation detection, uninitialized installations, virtual environments,
and Windows command paths. The dashboard retains passive release notices and
links to manual instructions; it does not install updates or restart the app.

## Compatibility and recovery

Version 0.4.0 retains application-data generation 2, profile schema 2, and
portable backup format 2. Data from 0.2.0, 0.2.1, 0.3.0, and 0.3.1 remains
compatible. These upgrades preserve the profile, Library, review progress,
and downloaded PDFs; no profile reset or backup import is needed. PDFs stay
in their chosen folder and are excluded from portable backups.

Earlier data generations cannot be opened or imported. Users of 0.1.x must
follow [Clean reset with recovery copy](../installation.md#clean-reset-with-recovery-copy)
and preserve the old state separately before creating new generation-2 state.

Automatic installation, environment snapshots, updater recovery, browser
restart handoffs, and updater-specific release manifests have been removed.
If an older installation has an unfinished automatic update, resolve it with
that version before upgrading. Keep its private recovery files, snapshots,
and backups intact; v0.4.0 does not use or delete them.

Daily-list recovery, abstract retrieval, and Library membership remain
separate. Retrying an abstract does not create a Review event, mark a date
reviewed, or save a paper to Library. The optional Interests sample does not
populate Review, Calendar, or Library. See [Troubleshooting](../troubleshooting.md)
for retrieval, launcher, backup, and installation help.
