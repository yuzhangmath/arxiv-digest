# arXiv Digest v0.3.1

Version 0.3.1 adds abstract retries to Review and orders Library by the date
of each paper's latest arXiv version. It retains application-data generation 2.

## Highlights

- When papers across unreviewed dates have blank abstracts, the Review starting
  page offers **Retry missing abstracts** with the affected-paper count. The
  retry fetches current metadata and shows progress while **Start review**
  remains available. Papers that still lack an abstract remain retryable.
- With search blank, Library shows saved papers by latest arXiv version date,
  newest first. Searches keep relevance first, then latest-version recency.

## Install or upgrade

Once this release is published, eligible 0.3.0 installations can select
**Update and restart** in the dashboard. Quit and relaunch arXiv Digest to run
a fresh release check. Wait for the new dashboard to report the update result,
then check your interests, Library, review progress, and PDF folder.

Automatic updates require the verified macOS/Linux pipx 1.16.7 installation
described in [Automatic updates](../installation.md#automatic-updates).
The release policy allows source versions from 0.3.0 inclusive to 0.3.1
exclusive. Unsupported installations keep a manual update link.

For versions 0.2.0 and 0.2.1, or a 0.3.0 installation requiring manual update,
follow the [generation-2 upgrade guide](../installation.md#upgrade-within-application-data-generation-2)
to quit, export a private backup, install the explicit `v0.3.1` tag, and verify
the saved state. Fresh installations should follow
[Install arXiv Digest](../installation.md#install-arxiv-digest), then run
`arxiv-digest init`. Users of 0.1.x must follow
[Clean reset with recovery copy](../installation.md#clean-reset-with-recovery-copy).

## Compatibility and recovery

This remains a prerelease for macOS and Linux, using updater protocol 1,
application-data generation 2, profile schema 2, and portable backup format 2.
Generation-2 upgrades preserve the profile, Library, review progress, and
downloaded PDFs. PDFs remain outside portable backups.

Daily-list recovery and abstract fetching are separate: a recovered date can
contain papers with missing abstracts. Retrying abstracts does not create
daily-list membership, mark dates reviewed, or save papers to Library.

If an update does not finish, follow the
[update recovery instructions](../troubleshooting.md#an-update-or-restart-did-not-finish).
